Honeytokens

Cebos únicos: sembralos en respuestas (un canary path en robots.txt, una api key falsa en un .env trampa). Si reaparecen en una request, el watcher dispara una alerta critical — señal de que el atacante usó lo que le servimos.

#tipotokendisparosúltimo

IPs ignoradas (whitelist)

IPs o rangos propios (monitor, infra nuestra). El watcher no genera alertas para ellos, se excluyen de los stats de Capturas y el replayer no los replica. Acepta host (1.2.3.4) o CIDR (172.104.0.0/16).

#IP / CIDRnota

Diccionario de vectores (wordlist)

Wordlist propio con los paths reales que piden los bots (ordenado por frecuencia). El server genera un snapshot diario automáticamente; o descargá uno fresco ahora con los filtros que quieras. Crudo (preserva ..%2f etc.), excluye IPs propias. Diccionarios oficiales: openbashok/attack-vectors.
